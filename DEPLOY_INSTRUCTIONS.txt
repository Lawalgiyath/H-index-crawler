================================================================================
  FASTEST DEPLOYMENT: RENDER.COM (100% FREE)
================================================================================

STEP 1: CREATE GITHUB REPOSITORY (5 minutes)
--------------------------------------------
1. Go to: https://github.com/new
2. Repository name: unilag-scholar-metrics
3. Make it: Public
4. Click: "Create repository"
5. Copy the repository URL (you'll need it next)

STEP 2: PUSH YOUR CODE (2 minutes)
-----------------------------------
Open Terminal/Command Prompt in your project folder and run:

git remote add origin https://github.com/YOUR_USERNAME/unilag-scholar-metrics.git
git branch -M main
git push -u origin main

(Replace YOUR_USERNAME with your actual GitHub username)

If it asks for credentials:
- Username: your GitHub username
- Password: use a Personal Access Token (create at github.com/settings/tokens)

STEP 3: DEPLOY ON RENDER.COM (3 minutes)
-----------------------------------------
1. Go to: https://render.com
2. Click: "Sign Up" (use GitHub for easy auth)
3. Click: "New +" button
4. Select: "Web Service"
5. Click: "Connect GitHub"
6. Authorize Render to access your repos
7. Select: unilag-scholar-metrics repository
8. Configure:
   Name: unilag-scholar-metrics
   Environment: Python 3
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn Crawlee:app
   Instance Type: Free
9. Click: "Create Web Service"

STEP 4: WAIT AND ACCESS (2-3 minutes)
--------------------------------------
- Render will build your app (~2 minutes)
- Watch the logs (optional)
- When done, you'll see: "Your service is live"
- Copy your URL: https://unilag-scholar-metrics.onrender.com

DONE! YOUR APP IS LIVE! 🎉

================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: Can't push to GitHub
SOLUTION: Create Personal Access Token at github.com/settings/tokens

ISSUE: Build failed on Render
SOLUTION: Check build logs, ensure requirements.txt is correct

ISSUE: App shows error
SOLUTION: Check Render logs (Logs tab in dashboard)

ISSUE: Can't upload files
SOLUTION: Check file size < 16MB, verify format is supported
